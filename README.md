Este repositorio contiene la solución a la práctica que solicita crear una función que calcule el área de un rectángulo e implementarla en dos lenguajes: C# y Python.
Objetivo:

Aplicar el concepto de funciones con retorno, las cuales reciben parámetros, procesan datos y devuelven un resultado.
La fórmula del área es:
área = base × altura
Se implementó esta lógica dentro de una función en C# y en Python.
